# kgghs-soc-c

경기여고 통합사회 공개 자료실([nyuheatgis.com/library.html](https://nyuheatgis.com/library.html))의 파일 저장소입니다.

## 자료 올리는 곳

학기 폴더 → 종류 폴더 순서로 넣습니다.

- `2026-1학기 통사C/학습지` · `2026-1학기 통사C/PPT` · `2026-1학기 통사C/참고자료`
- `2026-2학기 통사2C/학습지` · `2026-2학기 통사2C/PPT` · `2026-2학기 통사2C/참고자료`

- 새 학기에는 `2027-1학기 과목명`처럼 **`연도-1학기` 또는 `연도-2학기`로 시작하는 폴더**를 만들면 자료실에 자동으로 나타납니다. 최근 학기가 맨 위에 옵니다.
- 종류 폴더 이름은 `학습지`, `PPT`, `참고자료` 중 하나로 씁니다. 자료실의 종류 버튼은 이 세 이름만 알아봅니다.
- 이 규칙에 맞지 않는 최상위 폴더는 공개되지 않습니다. 예외로 예전 방식의 최상위 `학습지` · `PPT` · `참고자료` 폴더도 계속 공개됩니다.
- 올린 뒤 자료실에 보이기까지 몇 분 걸릴 수 있습니다.
